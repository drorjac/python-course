Getting started

Every lecture below has its slides (PDF) and its notebooks. Homework is on Moodle.

Course syllabus (PDF): topics, grading and the rules for using AI.

  1. Sign in to your Google account.
  2. Below, click Open in Colab next to a notebook. It opens in your browser.
  3. Click File → Save a copy in Drive. Now it is yours: edit anything.
  4. Run each cell with Shift+Enter. Guess the output before you run it!
  5. Notebooks that need a data file say so at the top. Upload it with the folder icon on the left, or run the "Plan B" cell that builds the same data for you.
