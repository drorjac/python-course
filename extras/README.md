# Going further (optional)

Extra notebooks for curious students: not in the homework, not on the exam. Every notebook was run
top to bottom and is saved with its results, so you can read it before running it.

## Big ideas

| Notebook | What it shows | Needs |
|---|---|---|
| `B1_white_black_gray_box.ipynb` | Three ways to find a law of nature. White box: the physics formula of a pendulum. Black box: a forest and a neural network learn it from 30 measurements, then fail outside the data. Gray box: measure gravity from the data, and a small symbolic-regression search that rediscovers T = 2.0·√L and, on real NASA planet data, Kepler's third law. Real-world uses: weather, rain from cellular links (TAU), medicine, digital twins | "Just run it": the code uses NumPy, pandas, Matplotlib and scikit-learn (Lectures 9-10) |
